# Happy Birthday Pookie!!

A self-contained interactive birthday card inspired by the reference TikTok: welcome screen, memory grid, soundtrack, letter teaser, opening prompt, and a confetti letter reveal.

## Run locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Customize

- Change the greeting and letter copy in `index.html`.
- Swap the six memory captions and card labels in `index.html`.
- Adjust colors and typography in `styles.css`.
- The soundtrack is an offline generated chime in `script.js`, so there are no external audio files or image dependencies.
